

# StudentApp

**Kelompok 1 – Pemrograman Aplikasi Bergerak**

StudentApp merupakan aplikasi berbasis mobile yang dikembangkan untuk membantu pengelolaan informasi mahasiswa dan data mata kuliah. Aplikasi ini menyediakan beberapa fitur, seperti melihat informasi, mengedit data, menghapus data, serta melihat daftar mata kuliah.

## Fitur Aplikasi

- Menampilkan halaman beranda.
- Mengelola dan mengedit data mahasiswa.
- Menghapus data.
- Menampilkan daftar mata kuliah.
